# Descripción
La funcionalidad del proyecto consiste en una plataforma analítica deportiva en tiempo real, la cual está diseñada para poder facilitar la toma de decisiones tácticas, físicas y gerenciales de un club de fútbol. El sistema actúa como un ayudante del cuerpo técnico porque ayuda con los expedientes históricos de los jugadores y contratos, analiza las interacciones tácticas en el campo y procesa los flujos masivos de datos y eventos del partido al instante. 

# Flujo de trabajo
Los datos que se van a utilizar para este proyecto vendrán de un archivo CSV/JSON. El script populate.py se encarga de leer la información de manera local, procesarla y ejecutar la inserción de los registros hacia las bases de datos. Para la consulta de los datos, el usuario va a poder ejecutar el archivo main.py y se le va a desplegar un menú el cual va a poder seleccionar una de las consultas predefinidas e ingresar los parámetros necesarios para que el sistema pueda hacer la petición a las bases de datos. Una vez que haga la petición, los resultados se mostrarán en la misma terminal.
